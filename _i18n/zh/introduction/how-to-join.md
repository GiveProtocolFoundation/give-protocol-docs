## 选择您的角色

Give Protocol 支持三种主要用户类型。选择最适合您的路径：

| 角色 | 描述 |
|------|------|
| **捐赠者** | 希望使用加密货币进行慈善捐赠的个人 |
| **慈善机构 / 组织** | 寻求接受捐款的非营利组织和经验证的组织 |
| **志愿者** | 向注册组织提供时间和技能的个人 |

## 第一步：创建账户

1. 访问 [app.giveprotocol.io](https://app.giveprotocol.io)
2. 点击**注册**
3. 输入您的电子邮件地址并创建密码
4. 通过确认链接验证您的电子邮件地址

## 第二步：连接您的钱包

Give Protocol 使用 Web3 钱包身份验证进行区块链交易。

**支持的钱包：**
- MetaMask
- 兼容 WalletConnect 的钱包
- Coinbase Wallet

连接步骤：
1. 点击顶部导航中的**连接钱包**
2. 选择您的钱包提供商
3. 在您的钱包中批准连接请求
4. 您的钱包地址现已与您的账户关联

## 第三步：完善您的个人资料

填写您的个人资料信息：
- 显示名称
- 个人头像（可选）
- 简介 / 描述
- 位置（可选）

## 第四步：选择您的路径

### 如果您是捐赠者

- 浏览[发现](/zh/platform-features/search-discovery/)页面寻找感兴趣的事业
- 开始捐赠无需额外验证
- 设置定期捐款或一次性捐款

### 如果您是组织

- 在账户设置中导航至**注册组织**
- 提交您的组织详情和法律文件
- 我们的团队将审核您的申请（通常需要 3-5 个工作日）
- 验证通过后，您的组织页面将正式上线

### 如果您是志愿者

- 完善您的技能档案
- 在平台上浏览志愿服务机会
- 申请机会并记录您的服务时间
